# 1.6.5 — Integration Test & Verification

## Objective

Create a comprehensive integration test suite for the Phase 1.6 multi-source ingestion (FRED, GDELT, Earnings Transcripts) and middleware updates — verify that all three new data sources ingest correctly, that the middleware can query them, and that the system handles each source's failure modes gracefully.

## Why This Matters

Phase 1.6 adds three distinct data sources, each with its own API, rate limits, and failure modes. Unlike Phase 1.3/1.4 (single-source ingestion), this phase has multiple moving parts that can fail independently. The test suite catches:

- API key misconfigurations (FRED key missing or invalid)
- Rate limiting or IP-based blocking (GDELT, Seeking Alpha)
- HTML structure changes (transcript page layouts change frequently)
- Empty data handling (tickers with no GDELT coverage)
- Cross-source integration bugs (macro data not appearing in middleware queries)
- New endpoint contract violations (missing fields, wrong status codes)

## Step 1: Create the Test Module

Create `tests/test_macros.py`:

```python

class TestMultiSourceIntegration:
    """End-to-end tests with all three sources."""

    @pytest.fixture
    def seeded_store(self, tmp_path):
        """Create a store seeded with data from all sources."""
        store = Store(db_path=tmp_path / "test.db")

        # FRED: macro indicators
        store.save_fundamental("MACRO", "FEDFUNDS", 4.5, "percent",
                               "2026-06-01", "daily", "fred")
        store.save_fundamental("MACRO", "CPIAUCSL", 3.2, "percent",
                               "2026-06-01", "daily", "fred")
        store.save_fundamental("MACRO", "UNRATE", 3.9, "percent",
                               "2026-06-01", "daily", "fred")

        # Earnings: guidance
        store.save_fundamental("NVDA", "guidance_revenue_low", 26.0,
                               "billion_usd", "2026-Q2", "quarterly",
                               "earnings_transcript")
        store.save_fundamental("NVDA", "guidance_revenue_high", 28.0,
                               "billion_usd", "2026-Q2", "quarterly",
                               "earnings_transcript")

        return store

    def test_macro_batch_retrieval(self, seeded_store):
        """Macro indicators can be retrieved as a batch."""
        macro = seeded_store.get_fundamentals_batch(
            "MACRO", metrics=["FEDFUNDS", "CPIAUCSL", "UNRATE"],
        )
        assert macro["FEDFUNDS"] == 4.5
        assert macro["CPIAUCSL"] == 3.2
        assert macro["UNRATE"] == 3.9

            "NVDA", metrics=["guidance_revenue_low", "guidance_revenue_high"],
        )
        assert guidance["guidance_revenue_low"] == 26.0
        assert guidance["guidance_revenue_high"] == 28.0

    def test_company_and_macro_together(self, seeded_store):

            "guidance_revenue_low", "guidance_revenue_high",

            "FEDFUNDS", "CPIAUCSL",
```
