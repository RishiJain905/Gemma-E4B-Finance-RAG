# 1.8.1 — System Integration & Final Wiring

## Objective

Connect every component of the RAG system into a single, coherent pipeline — the unified scheduler feeds all 6 data sources into the hybrid store, the middleware queries both stores with staleness awareness, and the TraceAlchemy model delivers grounded answers. This is the **final integration pass** that ensures no module is an island.

## Why This Matters

Phases 1.1–1.7 built each component in isolation. The scheduler orchestrates ingestion, the middleware handles queries, the storage layer holds data, and the model generates answers — but they've never been wired together end-to-end. Phase 1.8.1 closes every gap:

- The scheduler's `run_daily()` / `run_hourly()` / `run_weekly()` must actually populate the store that the middleware queries
- The middleware's `/refresh/{ticker}` endpoint must trigger the correct scheduler sources
- The staleness-aware query path must work with real (not mocked) data
- The IR ingestor must be registered in the scheduler's SOURCES dict
- The scheduler must be callable from the middleware's refresh path

## Step 2: Wire Scheduler into Middleware Refresh Path

The middleware's `_refresh_one_source()` in `src/middleware/app.py` currently calls each ingestor directly. For sources that have a scheduler-managed pipeline (SEC filings, earnings transcripts), the refresh should route through the `UnifiedScheduler` instead to ensure consistent TTL tracking and error handling.

Create a bridge function:

```python
def _refresh_via_scheduler(ticker: str, logical: str) -> None:
    """Route a per-ticker refresh through the UnifiedScheduler's source runner."""
    from src.scheduler import UnifiedScheduler
    sched = UnifiedScheduler(store=store)
    # Map logical source to scheduler source name
    SCHEDULER_SOURCE_MAP = {
        "sec_filings": "sec_filings",
        "earnings_transcripts": "earnings_transcripts",
        "ir_pages": "ir_pages",
    }
    source_name = SCHEDULER_SOURCE_MAP.get(logical)
    if source_name:
        sched._run_source(source_name, force=True)
    else:
        # Fall through to direct ingestion for non-scheduler sources
        _refresh_one_source_direct(ticker, logical)
```
