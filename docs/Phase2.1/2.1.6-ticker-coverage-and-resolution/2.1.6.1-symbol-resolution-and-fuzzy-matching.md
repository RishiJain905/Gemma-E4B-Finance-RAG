# 2.1.6.1 — Symbol Resolution & Fuzzy Matching

## Objective

Stop returning `ticker=None` for valid companies that aren't in the hardcoded
map. Add a **symbol resolver** that maps arbitrary company names (and tickers)
to symbols, tolerant of typos — so "blackbarry" → `BB`, "the chip company
nvidia" → `NVDA`.

## Why This Matters

Today `intent_parser._detect_ticker` only knows ~40 hardcoded names plus a
known-ticker set. Anything else → `ticker=None` → no retrieval → refusal. A real
resolver removes a whole class of "I don't have data" failures caused purely by
recognition, not by missing data.

## Step 1: Symbol resolver module

Create `src/middleware/symbol_resolver.py` with a `SymbolResolver`:
1. **Local first** — the existing `COMPANY_TO_TICKER` map + known tickers
   (fast, offline, no network).
2. **Catalog lookup** — a cached symbol catalog (name ↔ ticker) loaded from a
   provider: SEC `company_tickers.json` (already used in `edgar_fetcher`),
   and/or yfinance/FMP/Finnhub symbol search. Cache to
   `data/symbol_catalog.json` with a TTL.
3. **Fuzzy match** — when no exact hit, fuzzy-match the query tokens against
   catalog names (`rapidfuzz`), above a confidence threshold, to absorb typos.

```python
# sketch
class SymbolResolver:
    def resolve(self, text: str) -> Optional[str]:
        if (t := self._local(text)): return t           # map / known ticker
        if (t := self._catalog_exact(text)): return t    # name -> ticker
        return self._fuzzy(text)                          # typo-tolerant
```

**Files to create:** `src/middleware/symbol_resolver.py`
**Files to modify:** `requirements.txt` (`rapidfuzz`).

## Step 2: Wire into intent parsing

`IntentParser._detect_ticker` delegates to `SymbolResolver` after its existing
cheap checks, so behavior is a strict superset of today (no regressions for
currently-recognized names) plus new coverage. Keep the resolver injectable for
testing.

**Files to modify:** `src/middleware/intent_parser.py`.

## Step 3: Confidence + ambiguity handling

- Return a confidence score; below threshold → `None` (don't guess wildly).
- On ambiguous matches (e.g. "delta" → airline vs. others), prefer exact
  ticker/known-name, else the highest-confidence catalog hit; expose the
  resolved name so the answer can confirm ("Assuming BlackBerry (BB)…").
- Cache negative lookups briefly to avoid repeated misses.

## Step 4: Catalog refresh

Add a small CLI/util to (re)build `data/symbol_catalog.json` from the SEC
tickers file (no key) and optionally a provider; document running it. Gitignore
the cache file.

**Files to modify:** `.gitignore` (`data/symbol_catalog.json`), `scripts/` (a
`refresh_symbol_catalog.py` helper).
