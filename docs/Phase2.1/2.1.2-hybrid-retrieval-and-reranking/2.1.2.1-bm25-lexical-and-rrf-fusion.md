# 2.1.2.1 — BM25 Lexical Search & RRF Fusion

## Objective

Add a **lexical (keyword) retrieval channel** alongside the existing vector
search and fuse the two ranked lists with **Reciprocal Rank Fusion (RRF)**, so
exact terms (tickers, metric names, product names) that embeddings miss still
surface.

## Why This Matters

Vector search is great for meaning but weak on exact tokens — "MI300X",
"10-Q", "CRWD" can rank poorly. BM25 nails exact matches; fusing both is a
well-established, low-risk quality jump and the foundation for re-ranking
(2.1.2.2).

## Step 1: Build a BM25 index over documents

Add `src/middleware/lexical_index.py` with a `LexicalIndex` that indexes the
ChromaDB document corpus by id + text and supports `search(query, k)`.

- Use `rank_bm25` (`BM25Okapi`) — pure-Python, no service.
- Source the corpus from `Store.chroma` (ids, documents, metadata) via a new
  `ChromaStore.iter_documents()` helper.
- Tokenize consistently (lowercase, split on non-alphanumerics, keep tickers).
- Rebuild lazily and cache; expose `refresh()` for after ingestion.

```python
# src/middleware/lexical_index.py (sketch)
from rank_bm25 import BM25Okapi

class LexicalIndex:
    def __init__(self, store):
        self.store = store
        self._bm25 = None; self._ids = []

    def _build(self):
        ids, texts = self.store.chroma.iter_documents()
        self._ids = ids
        self._bm25 = BM25Okapi([self._tok(t) for t in texts])

    def search(self, query, k=10):
        if self._bm25 is None: self._build()
        scores = self._bm25.get_scores(self._tok(query))
        ranked = sorted(zip(self._ids, scores), key=lambda x: -x[1])[:k]
        return [{"id": i, "score": s} for i, s in ranked if s > 0]
```

**Files to create:** `src/middleware/lexical_index.py`
**Files to modify:** `src/storage/chroma_store.py` (add `iter_documents()`),
`requirements.txt` (`rank_bm25`).

## Step 2: RRF fusion in the retriever

In `src/middleware/retriever.py`, after getting vector results (existing) and
lexical results (new), fuse by RRF:

```python
def rrf_fuse(vector_hits, lexical_hits, k=60):
    scores = {}
    for rank, h in enumerate(vector_hits):
        scores[h["id"]] = scores.get(h["id"], 0) + 1.0 / (k + rank + 1)
    for rank, h in enumerate(lexical_hits):
        scores[h["id"]] = scores.get(h["id"], 0) + 1.0 / (k + rank + 1)
    return sorted(scores.items(), key=lambda x: -x[1])
```

Hydrate the fused ids back into full doc dicts (text + metadata) for the
downstream prompt augmenter. Keep the fused list size at `top_k_documents`.

**Files to modify:** `src/middleware/retriever.py`, `src/middleware/config.py`
(add `enable_lexical: bool`, `rrf_k: int`).
