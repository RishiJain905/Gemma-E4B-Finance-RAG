# 1.1.1 — Verify llama.cpp Build

## Objective

Confirm that your local `llama.cpp` installation is properly built and has all the capabilities required to serve the TraceAlchemy model. This is the foundation — if the build is broken or missing critical flags, nothing downstream works.

## Why This Matters

The `llama-server` binary is the runtime that loads your GGUF model and exposes an OpenAI-compatible API. Different builds of llama.cpp can have different compile-time flags — GPU acceleration (CUDA/Metal), flash attention, and context length limits are all set at build time. Running with a CPU-only build on an M4 would make inference unusably slow.

This task catches build issues before we invest time debugging slow inference or missing features.

## What We Need to Verify

### 1. Binary Exists
```bash
which llama-server
# Expected: /usr/local/bin/llama-server or similar
```

### 2. Build Info
```bash
llama-server --version
```
Look for:
- **Build target** — should match your hardware (e.g., `arm64` for M4 Mac)
- **GPU backend** — `Metal` for Apple Silicon, `CUDA` for NVIDIA, `SYCL` for Intel
- **Flash attention** — should show `flash-attn` in features

### 3. Quick Sanity Check
Run llama-server briefly to confirm it starts without crashing:
```bash
llama-server --help | head -20
```

### 4. Model File Check (Optional but Recommended)
```bash
# Check if the GGUF file is accessible and not corrupt
head -c 100 /path/to/TraceAlchemy-Gemma-4-E4B-Finance-IT.gguf | xxd | head -3
# GGUF files start with magic bytes: 0x47 0x47 0x55 0x46 ("GGUF")
```

## What Could Go Wrong

| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| `llama-server: command not found` | Not installed or not in PATH | Rebuild from source or install via brew: `brew install llama.cpp` |
| No GPU acceleration | Built without Metal/CUDA flag | Rebuild with `LLAMA_METAL=1` (macOS) or `LLAMA_CUDA=1` (NVIDIA) |
| Flash attention missing | Old build version | Update to latest: `git pull && cmake --build .` |
| GGUF file corrupt | Incomplete download | Re-download from Hugging Face, verify SHA256 |

## Verification

- [ ] `llama-server` binary found in PATH
- [ ] Build includes GPU acceleration (Metal for M4)
- [ ] Flash attention is available
- [ ] Server binary can start without immediate crash
