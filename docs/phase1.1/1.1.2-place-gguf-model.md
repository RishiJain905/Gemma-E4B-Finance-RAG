# 1.1.2 — Place the GGUF Model at a Stable Path

## Objective

Download (if not already done) and place the TraceAlchemy GGUF model file at a fixed, known location on your filesystem. Every downstream component — the server script, the middleware, the embedding pipeline — will reference this single path.

## Why This Matters

A stable model path eliminates a common class of bugs: "I moved the model file" or "I forgot where I put it." By deciding the path once and documenting it, every script and config file can hardcode the reference without guessing.

For a local-only setup like this, `~/models/tracealchemy/` is a natural home. It's in your user directory (no permissions issues), explicitly named after the project, and easy to type.

## Steps

### 1. Create the Model Directory
```bash
mkdir -p ~/models/tracealchemy
```

### 2. Download the Model (if you haven't already)
From Hugging Face:
```bash
# Install huggingface-cli if needed
pip install huggingface-hub

# Download the GGUF
huggingface-cli download \
  trjxter/TraceAlchemy-Gemma-4-E4B-Finance-IT-gguf \
  --local-dir ~/models/tracealchemy \
  --local-dir-use-symlinks False
```

Alternatively, if you already have the file downloaded elsewhere:
```bash
mv /path/to/your/download/TraceAlchemy-Gemma-4-E4B-Finance-IT.gguf \
   ~/models/tracealchemy/
```

### 3. Verify the File
```bash
ls -lh ~/models/tracealchemy/
# Expected: TraceAlchemy-Gemma-4-E4B-Finance-IT.gguf (~9.6 GB)
```

Check file integrity:
```bash
# GGUF magic bytes check
head -c 4 ~/models/tracealchemy/TraceAlchemy-Gemma-4-E4B-Finance-IT.gguf | xxd
# Should show: 47 47 55 46 (GGUF)
```

### 4. (Optional) Verify SHA256
If Hugging Face provides a checksum:
```bash
sha256sum ~/models/tracealchemy/TraceAlchemy-Gemma-4-E4B-Finance-IT.gguf
```

## The Canonical Path

After this task, the model lives at:
```
~/models/tracealchemy/TraceAlchemy-Gemma-4-E4B-Finance-IT.gguf
```

This path is used by:
- `scripts/serve_model.sh` (Task 1.1.5)
- The middleware configuration (Phase 1.5)
- Any future scripts that need to reference the model

## What Could Go Wrong

| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| Download interrupted mid-file | Network issue or timeout | Re-run download with `--resume` |
| Wrong file format (safetensors, not GGUF) | Downloaded wrong asset from HF | Check you're downloading the `.gguf` file, not the source safetensors |
| Disk space | ~9.6 GB required | Check with `df -h ~/models/` |
| Permission denied | `mv` across filesystems | Use `cp` then `rm`, or download directly to target |
