# 1.1.2 — Place the GGUF Model at a Stable Path

## Objective

Ensure the TraceAlchemy GGUF model file is downloaded and sitting at a fixed, known location on your Windows machine. Every downstream component — the server script, the middleware, the embedding pipeline — will reference this single path.

## Why This Matters

A stable model path eliminates a common class of bugs: "I moved the model file" or "I forgot where I put it." By deciding the path once and documenting it in `configs/model.yaml`, every script can reference the canonical location.

Your model already lives at:
```
D:\LOCAL-MODELS\trjxter\TraceAlchemy-Gemma-4-E4B-Finance-IT-gguf\gemma-4-E4B-it.Q8_0.gguf
```

This task confirms the file is intact and records the path.

## Steps

### 1. Verify the Model Exists

```powershell
# Open PowerShell and check
Get-Item "D:\LOCAL-MODELS\trjxter\TraceAlchemy-Gemma-4-E4B-Finance-IT-gguf\gemma-4-E4B-it.Q8_0.gguf"
```

Expected output shows the file with its size.

### 2. Check File Size

```powershell
(Get-Item "D:\LOCAL-MODELS\trjxter\TraceAlchemy-Gemma-4-E4B-Finance-IT-gguf\gemma-4-E4B-it.Q8_0.gguf").Length / 1GB
```

**Expected:** ~9.6 GB for the Q8_0 quant. If significantly smaller, the download may be incomplete.

### 3. Verify GGUF Integrity

GGUF files start with the magic bytes `GGUF` (hex: `47 47 55 46`):

```powershell
# Read first 4 bytes
$bytes = [System.IO.File]::ReadAllBytes("D:\LOCAL-MODELS\trjxter\TraceAlchemy-Gemma-4-E4B-Finance-IT-gguf\gemma-4-E4B-it.Q8_0.gguf")[0..3]
[string]::Join(" ", $bytes.ForEach({ "0x{0:X2}" -f $_ }))
```

Expected: `0x47 0x47 0x55 0x46`

### 4. Confirm the Draft Model (MTP Head)

Your config also uses a draft model for speculative decoding:

```powershell
Get-Item "D:\LOCAL-MODELS\AtomicChat\gemma-4-E4B-it-assistant-GGUF\gemma-4-E4B-it-assistant.F16.gguf"
```

This is the MTP (Multi-Token Prediction) head model. It should exist alongside the main model.

## What Could Go Wrong

| Problem | Likely Cause | Fix |
|---------|-------------|------|
| File not found | Wrong path or drive letter | Double-check the actual location in File Explorer |
| File too small | Incomplete download | Re-download from Hugging Face, ensure complete |
| Wrong quant type | Downloaded Q4 instead of Q8_0 | Check filename — should be `Q8_0.gguf` not `Q4_K_M.gguf` |
| Draft model missing | Not downloaded from HF | Download `trjxter/TraceAlchemy-Gemma-4-E4B-Finance-IT-gguf` companion models |
