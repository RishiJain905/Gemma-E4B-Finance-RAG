# 1.1.5 — Create a Server Wrapper Script

## Objective

Build a shell script that starts `llama-server` with the correct flags every time, eliminating the need to remember or retype the full command. The script should also support stopping the server cleanly.

## Why This Matters

The `llama-server` command from Task 1.1.3 is ~5 lines long with multiple flags. Typing it manually is error-prone — one typo in a flag and you get a confusing error, or worse, it runs with suboptimal settings and you don't notice. A wrapper script:

1. **Standardizes** the command — every start is identical
2. **Documents** the settings — anyone reading the script sees the configuration
3. **Convenience** — `./scripts/serve_model.sh` is easier than a 5-line command
4. **Stop logic** — the script should also handle graceful shutdown

## The Script

Create `scripts/serve_model.sh` at the project root:

```bash
#!/usr/bin/env bash
set -euo pipefail

# ──────────────────────────────────────────────
# TraceAlchemy llama-server Wrapper
# Usage: ./scripts/serve_model.sh [start|stop|restart|status] [port]
# ──────────────────────────────────────────────

MODEL_PATH="$HOME/models/tracealchemy/TraceAlchemy-Gemma-4-E4B-Finance-IT.gguf"
PORT="${2:-8080}"
LOG_DIR="$HOME/models/tracealchemy/logs"
PID_FILE="$LOG_DIR/server.pid"
LOG_FILE="$LOG_DIR/server.log"

ACTION="${1:-start}"

ensure_log_dir() {
    mkdir -p "$LOG_DIR"
}

start_server() {
    ensure_log_dir

    if [ -f "$PID_FILE" ] && kill -0 "$(cat "$PID_FILE")" 2>/dev/null; then
        echo "❌ Server is already running (PID $(cat "$PID_FILE")). Use 'stop' first or 'restart'."
        exit 1
    fi

    echo "🚀 Starting TraceAlchemy on port $PORT..."

    nohup llama-server \
        -m "$MODEL_PATH" \
        --port "$PORT" \
        --host 127.0.0.1 \
        --ctx-size 32768 \
        --n-gpu-layers 99 \
        --rope-scaling none \
        --flash-attn 1 \
        --parallel 1 \
        --cont-batching 1 \
        > "$LOG_FILE" 2>&1 &

    PID=$!
    echo $PID > "$PID_FILE"

    echo "✅ Server started (PID $PID)"
    echo "   Logs: $LOG_FILE"
    echo "   API:  http://127.0.0.1:$PORT"

    # Wait briefly and check if it's still alive (immediate crash detection)
    sleep 2
    if kill -0 $PID 2>/dev/null; then
        echo "   Status: running"
    else
        echo "   ⚠️  Server exited prematurely. Check logs:"
        tail -5 "$LOG_FILE"
        exit 1
    fi
}

stop_server() {
    if [ ! -f "$PID_FILE" ]; then
        echo "ℹ️  No PID file found. Server may not be running."
        # Try to find and kill any llama-server on the port
        local pids
        pids=$(lsof -ti :"$PORT" 2>/dev/null || true)
        if [ -n "$pids" ]; then
            echo "   Found llama-server on port $PORT. Stopping..."
            kill $pids 2>/dev/null || true
            echo "✅ Stopped."
        else
            echo "   No server found on port $PORT."
        fi
        return
    fi

    local pid
    pid=$(cat "$PID_FILE")

    if kill -0 "$pid" 2>/dev/null; then
        echo "🛑 Stopping TraceAlchemy (PID $pid)..."
        kill "$pid"
        # Wait for graceful shutdown
        for i in $(seq 1 10); do
            if ! kill -0 "$pid" 2>/dev/null; then
                break
            fi
            sleep 1
        done
        # Force kill if still alive
        if kill -0 "$pid" 2>/dev/null; then
            echo "   Force killing..."
            kill -9 "$pid" 2>/dev/null || true
        fi
        echo "✅ Server stopped."
    else
        echo "ℹ️  PID $pid is not running. Cleaning up PID file."
    fi

    rm -f "$PID_FILE"
}

status_server() {
    if [ -f "$PID_FILE" ] && kill -0 "$(cat "$PID_FILE")" 2>/dev/null; then
        local pid
        pid=$(cat "$PID_FILE")
        local uptime
        uptime=$(ps -o etime= -p "$pid" | xargs)
        echo "✅ TraceAlchemy is running"
        echo "   PID:     $pid"
        echo "   Port:    $PORT"
        echo "   Uptime:  $uptime"
        echo "   Logs:    $LOG_FILE"

        # Quick health check
        if curl -sf http://127.0.0.1:"$PORT"/v1/completions \
             -H "Content-Type: application/json" \
             -d '{"prompt": "test", "max_tokens": 1}' > /dev/null 2>&1; then
            echo "   API:     responding ✅"
        else
            echo "   API:     not responding ❌"
        fi
    else
        echo "❌ TraceAlchemy is not running"
        rm -f "$PID_FILE"
    fi
}

case "$ACTION" in
    start)
        start_server
        ;;
    stop)
        stop_server
        ;;
    restart)
        stop_server
        sleep 1
        start_server
        ;;
    status)
        status_server
        ;;
    *)
        echo "Usage: $0 {start|stop|restart|status} [port]"
        echo ""
        echo "Examples:"
        echo "  $0 start          Start on default port 8080"
        echo "  $0 start 8081     Start on port 8081"
        echo "  $0 status         Check if server is running"
        echo "  $0 stop           Stop the server"
        echo "  $0 restart        Restart the server"
        exit 1
        ;;
esac
```

Make it executable:

```bash
chmod +x scripts/serve_model.sh
```

## Usage

```bash
# Start the server
./scripts/serve_model.sh start

# Start on a different port
./scripts/serve_model.sh start 8081

# Check status
./scripts/serve_model.sh status

# Stop gracefully
./scripts/serve_model.sh stop

# Restart
./scripts/serve_model.sh restart
```

## What the Script Does

1. **Defines constants** — model path, default port, log directory
2. **`start`** — launches `llama-server` in background with `nohup`, saves PID, waits 2s to confirm it didn't crash immediately
3. **`stop`** — sends SIGTERM, waits up to 10s for graceful shutdown, then SIGKILL if needed. Also cleans up stale PID files
4. **`status`** — checks if the server process exists, reports uptime, and does a quick API health check
5. **`restart`** — stop then start

## Log Files

All server output goes to:
```
~/models/tracealchemy/logs/server.log
~/models/tracealchemy/logs/server.pid
```

Check the log if something goes wrong:
```bash
tail -f ~/models/tracealchemy/logs/server.log
```

## Future: Systemd / Launchd Service (Optional)

For a more permanent setup, you can register this as a macOS launchd service so the server starts automatically on boot:

```xml
<!-- ~/Library/LaunchAgents/com.tracealchemy.llamaserver.plist -->
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.tracealchemy.llamaserver</string>
    <key>ProgramArguments</key>
    <array>
        <string>/path/to/project/scripts/serve_model.sh</string>
        <string>start</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
</dict>
</plist>
```

This is optional and can be set up later — the wrapper script is sufficient for now.
