# 1.3.4 — Scheduling & Incremental Updates

## Objective

Add cache-aware scheduling to the YFinance ingestor so it only fetches data that's stale. Implement macro indicator ingestion and create the `ingest_stale_only()` method for production use.

## Why This Matters

Running `ingest_all()` every time is wasteful — most tickers' data is still fresh. This module makes ingestion **incremental**: it uses the cache_meta table to skip tickers whose data isn't stale yet, and only fetches what's needed.

This is the difference between:
- Naive: Re-fetch 19 tickers × 18 fundamentals × N news articles every run
- Smart: Check which tickers have stale cache → only fetch those 2-3 tickers

## Step 2: Add Stale-Only Ingestion

Add these methods to `src/ingestion/yfinance_ingestor.py`:

```python
    # ── Incremental / Stale-Only Ingestion ────────────

    def ingest_stale_only(self):
        """Only ingest tickers with stale fundamentals or news."""
        logger.info("Checking for stale cache entries...")

        stale_entries = self.store.get_stale_entries(limit=50)
        if not stale_entries:
            logger.info("All cache entries are fresh — nothing to ingest.")
            return

        logger.info("Found %d stale cache entries", len(stale_entries))

        # Group by ticker to avoid duplicate fetches
        tickers_needing_fundamentals = set()
        tickers_needing_news = set()

        for entry in stale_entries:
            ticker = entry["ticker"]
            source = entry.get("source")

            if source and "fundamental" in source:
                tickers_needing_fundamentals.add(ticker)
            elif source and "news" in source:
                tickers_needing_news.add(ticker)

        # Ingest stale fundamentals
        for ticker in tickers_needing_fundamentals:
            logger.info("Stale fundamentals for %s — fetching...", ticker)
            t = self._fetch_ticker(ticker)
            if t:
                self._ingest_ticker_fundamentals(ticker, t)

        # Ingest stale news (may have been updated by fundamentals run above)
        still_stale_news = tickers_needing_news - tickers_needing_fundamentals
        for ticker in still_stale_news:
            logger.info("Stale news for %s — fetching...", ticker)
            t = self._fetch_ticker(ticker)
            if t:
                self._ingest_ticker_news(ticker, t)

        # Any tickers that had fundamentals run also need fresh news
        if tickers_needing_fundamentals:
            logger.info("Re-fetching news for %d tickers that just got fresh fundamentals...",
                        len(tickers_needing_fundamentals))
            # Only if news cache is also stale or non-existent
            for ticker in tickers_needing_fundamentals:
                if ticker in tickers_needing_news or self._news_fresh(ticker):
                    continue  # Already fresh or already queued
                t = self._fetch_ticker(ticker)
                if t:
                    self._ingest_ticker_news(ticker, t)

    def reset_cache_all(self):
        """Force all cache entries to stale — next run will re-fetch everything."""
        logger.warning("Resetting ALL cache entries to stale...")
        for ticker in self.all_tickers:
            self.store.mark_cache_stale(ticker, "yfinance_fundamentals")
            self.store.mark_cache_stale(ticker, "yfinance_news")
        # Also reset macro
        for ticker in self.watchlist.get("macro_tickers", []):
            self.store.mark_cache_stale(ticker, "yfinance_macro")
        logger.info("All cache entries marked stale. Next ingest will re-fetch everything.")

    def status_report(self) -> dict:
        """Print a status report of what's fresh and what's stale."""
        report = {"fresh": 0, "stale": 0, "not_cached": 0, "details": []}

        for ticker in self.all_tickers:
            fund_status = self.store.sqlite.get_cache_status(ticker, "yfinance_fundamentals")
            news_status = self.store.sqlite.get_cache_status(ticker, "yfinance_news")

            entry = {
                "ticker": ticker,
                "fundamentals": fund_status["status"] if fund_status else "not_cached",
                "news": news_status["status"] if news_status else "not_cached",
            }

            if fund_status and news_status:
                if fund_status["status"] == "fresh" and news_status["status"] == "fresh":
                    report["fresh"] += 1
                else:
                    report["stale"] += 1
            else:
                report["not_cached"] += 1

            report["details"].append(entry)

        return report
```

## Step 3: Macro Indicator Ingestion

Add macro ingestion — these aren't tied to a company ticker but provide market context:

```python
    # ── Macro Indicators ──────────────────────────────

    MACRO_METRICS = [
        ("price",          "regularMarketPrice",     "usd",      "point_in_time"),
        ("change_percent", "regularMarketChangePercent", "percent", "point_in_time"),
        ("volume",         "regularMarketVolume",    "shares",   "point_in_time"),
        ("day_range_low",  "regularMarketDayLow",    "usd",      "point_in_time"),
        ("day_range_high", "regularMarketDayHigh",   "usd",      "point_in_time"),
        ("fifty_two_week_low",  "fiftyTwoWeekLow",   "usd",      "point_in_time"),
        ("fifty_two_week_high", "fiftyTwoWeekHigh",  "usd",      "point_in_time"),
    ]

    def ingest_macro(self):
        """Ingest macro indicators (index ETFs and broad market data)."""
        macro_tickers = self.watchlist.get("macro_tickers", [])
        if not macro_tickers:
            logger.info("No macro tickers configured, skipping macro ingestion")
            return

        logger.info("Ingesting macro indicators for %d tickers...", len(macro_tickers))
        saved = 0
        skipped = 0

        for ticker in macro_tickers:
            # Cache check
            if self._macro_fresh(ticker):
                skipped += 1
                continue

            t = self._fetch_ticker(ticker)
            if t is None:
                continue

            info = t.info
            period_label = self._current_period_label()

            for metric_name, info_key, unit, period_type in self.MACRO_METRICS:
                raw_value = info.get(info_key)
                if raw_value is None:
                    continue
                value = self._normalize_value(raw_value)
                if value is None:
                    continue

                self.store.save_fundamental(
                    ticker=ticker,
                    metric=metric_name,
                    value=value,
                    unit=unit,
                    period=period_label,
                    period_type=period_type,
                    source_type="yfinance_macro",
                )
                saved += 1

            ttl_hours = self.watchlist.get("schedule", {}).get("macro", 24)
            self.store.mark_cache_fresh(ticker, "yfinance_macro", ttl_hours)

        logger.info("Macro ingestion complete: %d metrics saved, %d skipped (fresh)", saved, skipped)

    def _macro_fresh(self, ticker: str) -> bool:
        """Check if macro cache is still fresh."""
        ttl_hours = self.watchlist.get("schedule", {}).get("macro", 24)
        status = self.store.sqlite.get_cache_status(ticker, "yfinance_macro")
        if status and status.get("status") == "fresh":
            from datetime import datetime, timezone
            accessed = status.get("accessed_at")
            if accessed:
                age_hours = (datetime.now(timezone.utc) - accessed).total_seconds() / 3600
                return age_hours < ttl_hours
        return False
```

## What Could Go Wrong

| Problem | Likely Cause | Fix |
|---------|-------------|------|
| `get_stale_entries()` returns empty but cache was reset | TTL hasn't expired yet | Reduce TTLs temporarily for testing, or use `mark_cache_stale()` |
| Macro tickers like SPY don't have fundamentals | They're ETFs, not companies | That's expected — macro only stores the `MACRO_METRICS` fields |
| `reset_cache_all()` doesn't clear all entries | Different source name used | Check `cache_meta` contents with the SQL query from Step 1 |
| Stale-only misses some tickers | Cache entry never existed (not_cached) | `get_stale_entries` returns stale + not_cached — verify query |
| News ingest fails because fundamentals aren't cached | News depends on fundamentals first | The `_ingest_ticker_news` checks fundamentals status and fetches them |
