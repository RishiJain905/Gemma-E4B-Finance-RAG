# 1.3.3 — News & Summary Ingestion

## Objective

Pull recent news articles and analyst summaries from Yahoo Finance for each core ticker, embed them via ChromaDB, and store them as searchable documents alongside the structured fundamentals.

## Why This Matters

Fundamentals (revenue, EPS, margins) tell you **what** happened. News and summaries tell you **why** it happened and **what's expected next**. This is the semantic layer that makes your RAG system useful — when you ask "why did NVDA drop today?", the answer comes from news embeddings, not from a P/E ratio.

Yahoo Finance provides ticker-specific news with headlines, summaries, publisher info, and timestamps — all free.

## Step 1: Add News Ingestion to YFinanceIngestor

Add these methods to `src/ingestion/yfinance_ingestor.py`:

```python
    # ── News Ingestion ────────────────────────────────

    def ingest_news(self):
        """Ingest recent news for all core tickers."""
        logger.info("Ingesting news for %d core tickers...", len(self.core_tickers))
        success_count = 0
        skip_count = 0

        for ticker in self.core_tickers:
            # Cache check — skip if news is still fresh
            if self._news_fresh(ticker):
                logger.debug("Ticker %s news is fresh, skipping", ticker)
                skip_count += 1
                continue

            # Also skip if fundamentals haven't been fetched yet
            status = self.store.sqlite.get_cache_status(ticker, "yfinance_fundamentals")
            if not status or status.get("status") != "fresh":
                logger.info("Ticker %s fundamentals not yet ingested, doing fundamentals first", ticker)
                t = self._fetch_ticker(ticker)
                if t:
                    self._ingest_ticker_fundamentals(ticker, t)

            # Now do news
            t = self._fetch_ticker(ticker)
            if t is None:
                continue

            self._ingest_ticker_news(ticker, t)
            success_count += 1

        logger.info(
            "News ingestion complete: %d ingested, %d skipped (fresh)",
            success_count, skip_count
        )

    def _news_fresh(self, ticker: str) -> bool:
        """Check if news cache is still fresh for this ticker."""
        ttl_hours = self.watchlist.get("schedule", {}).get("news", 6)
        status = self.store.sqlite.get_cache_status(ticker, "yfinance_news")
        if status and status.get("status") == "fresh":
            from datetime import datetime, timezone
            accessed = status.get("accessed_at")
            if accessed:
                age_hours = (datetime.now(timezone.utc) - accessed).total_seconds() / 3600
                return age_hours < ttl_hours
        return False

    def _ingest_ticker_news(self, ticker: str, t):
        """Ingest recent news for a single ticker and store as ChromaDB docs."""
        try:
            news_raw = t.news
        except Exception as e:
            logger.warning("Ticker %s news fetch failed: %s", ticker, e)
            return

        if not news_raw:
            logger.info("Ticker %s has no news articles to ingest", ticker)
            return

        saved = 0
        skipped = 0
        for article in news_raw:
            doc_id = self._make_news_doc_id(ticker, article)
            text = self._format_news_article(article)
            if text is None:
                skipped += 1
                continue

            # Check if already stored (idempotent)
            existing = self.store.chroma.get_document(doc_id)
            if existing:
                skipped += 1
                continue

            date_str = article.get("providerPublishTime")
            if date_str and isinstance(date_str, (int, float)):
                from datetime import datetime
                date_str = datetime.utcfromtimestamp(date_str).strftime("%Y-%m-%d")

            self.store.save_document(
                document_id=doc_id,
                text=text,
                ticker=ticker,
                source="yfinance_news",
                date=date_str or "",
                metadata={
                    "title": article.get("title", ""),
                    "publisher": article.get("publisher", ""),
                    "link": article.get("link", ""),
                    "type": article.get("type", "news"),
                },
            )
            saved += 1

        # Mark cache as fresh
        ttl_hours = self.watchlist.get("schedule", {}).get("news", 6)
        self.store.mark_cache_fresh(ticker, "yfinance_news", ttl_hours)
        logger.info(
            "Ticker %s: %d news articles saved, %d skipped, cache marked fresh (%dh)",
            ticker, saved, skipped, ttl_hours
        )

    def _make_news_doc_id(self, ticker: str, article: dict) -> str:
        """Create a unique document ID for a news article."""
        # Use UUID-like prefix from the link for dedup
        link = article.get("link", "")
        # Take last segment of URL as unique ID
        url_id = link.rstrip("/").rsplit("/", 1)[-1] if link else str(hash(article.get("title", "")))
        return f"news/{ticker}/{url_id}"

    def _format_news_article(self, article: dict) -> str:
        """Format a news article into a searchable document text."""
        title = article.get("title", "")
        summary = article.get("summary", "")
        publisher = article.get("publisher", "")

        if not title and not summary:
            return None

        parts = []
        if title:
            parts.append(f"# {title}")
        if summary:
            parts.append(summary)
        if publisher:
            parts.append(f"—— Source: {publisher}")

        return "\n\n".join(parts)
```

## News Article Structure

Yahoo Finance news articles come with these fields:

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Headline |
| `summary` | string | Short description (1-3 sentences) |
| `publisher` | string | News source (e.g., "Reuters", "Bloomberg") |
| `link` | string | URL to full article |
| `providerPublishTime` | int | Unix timestamp of publication |
| `type` | string | Usually "STORY" or "NEWS" |
| `relatedTickers` | list | Tickers mentioned in the article |

## What Could Go Wrong

| Problem | Likely Cause | Fix |
|---------|-------------|------|
| `t.news` returns empty list | Ticker may have no recent news | Skip gracefully (already handled) |
| `t.news` raises exception | Network issue or Yahoo rate limit | Add retry/backoff in `_fetch_ticker` |
| Article has no title/summary | Malformed article object | Skip with `None` return (already handled) |
| Duplicate news articles | Same article fetched in consecutive runs | `get_document` check prevents re-embedding |
| Embedding takes too long | Many articles + batch embed | Reduce articles or increase timeout |
| News doc IDs collide | Two articles with similar URLs | Current ID scheme uses last URL segment — rare collisions, log warning |
| Cache says fresh but no news in DB | TTL expired between check and ingest | Add a `ttl_grace_period` or skip cache on first run |
