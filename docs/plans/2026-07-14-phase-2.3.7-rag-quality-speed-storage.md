# Phase 2.3.7 RAG Quality, Speed, and Storage Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make corpus-capability answers complete, improve indirect-query routing, bypass generation for proven deterministic answers, scale hybrid retrieval, and make the database decision from measured gates.

**Architecture:** Add an authoritative catalog lane and explicit answer obligations ahead of existing adaptive retrieval. Use stable corpus-ledger chunk ids to maintain SQLite FTS5 beside Chroma, retain RRF/reranking, and expose a guarded deterministic response exit. Keep SQLite + Chroma unless the reproducible storage benchmark triggers a separately approved replacement pilot.

**Tech Stack:** Python, FastAPI/Pydantic, SQLite/FTS5, ChromaDB, pytest, existing evaluation harness, YAML configuration, PowerShell/Bash verify gates.
