# 1.2.1 — Project Structure & Dependencies

## Objective

Create the Python project scaffolding, install dependencies, and establish the directory layout for the ingestion and storage layers. This is the foundation that all subsequent phases build on.

## Why This Matters

A clean project structure prevents the "where does this file go?" problem as the codebase grows. By setting up the layout, virtual environment, and requirements up front, every script knows exactly where to import from and what dependencies are available.

We're also being deliberate about **Hermes agent integration** — the Linux Hermes agent will trigger ingestion scripts on your Windows machine (or the scripts can run standalone). The structure supports both modes.

## Directory Layout

Create the following structure under the project root:

```
Gemma-E4B-Finance-RAG/
├── configs/
│   ├── model.yaml              # Already exists — model params
│   └── storage.yaml            # NEW — DB paths, collection names
├── data/
│   ├── chroma/                 # ChromaDB persistent storage
│   ├── staging/                # Raw downloads before processing
│   └── finance.db              # SQLite database file
├── src/
│   ├── __init__.py
│   ├── storage/
│   │   ├── __init__.py
│   │   ├── sqlite_store.py     # SQLite operations (Task 1.2.2)
│   │   ├── chroma_store.py     # ChromaDB operations (Task 1.2.3)
│   │   └── store.py            # Unified abstraction (Task 1.2.4)
│   ├── ingestion/              # Placeholder for Phase 1.3+
│   │   └── __init__.py
│   └── middleware/              # Placeholder for Phase 1.5
│       └── __init__.py
├── scripts/
│   ├── serve_model.ps1         # Already exists
│   ├── serve_model.sh
│   └── seed_test_data.py       # Integration test (Task 1.2.5)
├── tests/
│   └── test_storage.py         # Unit tests for storage layer
└── requirements.txt
```

## Steps

### 1. Create Directories

```powershell
# From the project root
mkdir -p src/storage src/ingestion src/middleware
mkdir -p data/chroma data/staging
mkdir -p tests
```

### 2. Create Python Package Init Files

Create `__init__.py` files so Python treats these as packages:

```powershell
# Create empty __init__.py files
New-Item -ItemType File -Path src/__init__.py
New-Item -ItemType File -Path src/storage/__init__.py
New-Item -ItemType File -Path src/ingestion/__init__.py
New-Item -ItemType File -Path src/middleware/__init__.py
```

### 3. Create requirements.txt

```txt
# requirements.txt
# ── Core ──────────────────────────────────────────────
chromadb>=0.6.0
numpy>=1.24.0

# ── Web / API ─────────────────────────────────────────
httpx>=0.27.0          # HTTP client for llama-server API
requests>=2.31.0       # Fallback HTTP client

# ── Data Processing ───────────────────────────────────
pydantic>=2.0.0        # Data validation / schemas
python-dateutil>=2.8.0 # Date parsing

# ── Ingestion (Phase 1.3+) ───────────────────────────
yfinance>=0.2.0        # Yahoo Finance data
sec-edgar-api>=1.0.0   # SEC EDGAR filings
gdelt>=1.0.0           # GDELT news
fredapi>=0.5.0         # FRED economic data

# ── Testing ───────────────────────────────────────────
pytest>=8.0.0
```

### 4. Install Dependencies

```powershell
# Create a virtual environment
python -m venv .venv

# Activate it
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### 5. Create storage.yaml Config

```yaml
# configs/storage.yaml
# Storage layer configuration

sqlite:
  path: "data/finance.db"

chroma:
  path: "data/chroma"
  collection_name: "tracealchemy_docs"
  embedding_dimension: 2048  # Fill after confirming in Task 1.1.7

embedding:
  provider: "llama-server"
  endpoint: "http://127.0.0.1:8087/v1/embeddings"
  model: "tracealchemy"
  pooling: "mean"
  batch_size: 10

cache:
  default_ttl_hours: 24
  filing_ttl_hours: 168  # SEC filings: 7 days
  earnings_ttl_hours: 336 # Earnings transcripts: 14 days
```

### 6. Create a .gitignore for the Data Directory

```gitignore
# .gitignore additions

# Data files (generated, not committed)
data/
*.db
*.sqlite

# Virtual environment
.venv/
venv/

# Python cache
__pycache__/
*.pyc
*.pyo
```
